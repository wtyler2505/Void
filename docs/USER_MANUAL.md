## 1. 𝗧𝗛𝗘 𝗜𝗡𝗧𝗘𝗥𝗙𝗔𝗖𝗘

### A. The Sidebar (Navigation)
The command center for your knowledge base. Drag-resizable (240–600px).

*   **Search**: Real-time filtering by title, content, or tags (`Ctrl + F`).
*   **Breadcrumbs**: Path display — `VOID > Notes/Archive/Trash > tag > title`.
*   **Folders**: Nested folder hierarchy for organizing notes. Persisted in localStorage.
*   **Tag Lattice**: Color-coded tags with hash-based unique colors. Click to filter.
*   **Action Grid**: New Note, Templates, Neural Fusion, Live Session, Sync, Pinned Notes, Recent Notes, Trash.
*   **Note List**: Arrow-key navigable. Multi-select for bulk archive/trash. Drag-and-drop for Fusion.
*   **Sort**: By updated, created, alphabetical, or size.
*   **View Density**: Compact or comfortable layout toggle.
*   **Storage Indicator**: Visual localStorage usage meter.
*   **Quick Capture**: Floating button for instant note creation.

### B. The Editor (Workspace)
Where the magic happens.

*   **Title**: Auto-generated by AI if left blank (based on content).
*   **Toolbar**: AI tools (Summarize, Enhance, Visualize, Video, TTS), Split-Pane, Haunt, Zen Mode, Pomodoro Timer, Table Insert, Markdown Cheat Sheet (`MD?`).
*   **Slash Commands**: Type `/` to insert headings, lists, code blocks, tables inline.
*   **Split-Pane**: Edit two notes side by side, or show live Markdown preview.
*   **Zen Mode**: Distraction-free fullscreen writing.
*   **Code Highlighting**: Syntax-highlighted code blocks (VS Code Dark+ theme).
*   **Interactive Checklists**: Clickable checkboxes with progress tracking bar.
*   **Footnotes**: `[^1]` style inline references and annotations.
*   **Wiki Links**: Type `[[` for autocomplete-powered note-to-note linking.
*   **Link Previews**: Paste URLs to generate embeddable preview cards (favicon + domain).
*   **Pomodoro Timer**: 25/5 work/break cycles for focused writing sessions.
*   **Version History**: Timeline-based undo — browse and restore previous note states.
*   **Word Count Goals**: Set targets and track writing streaks.
*   **Daily Journal Prompt**: AI-generated prompt to kickstart daily entries.
*   **Footer**: Word count, read time, goal progress, streak, last saved timestamp.

### C. The Chat Overlay (Assistant)
A floating window activated by the "Chat" button.

*   **Context Aware**: The AI knows which note you are currently editing.
*   **Omnipotent**: Tell it to "Delete this," "Make a new note," "Add a tag," or "Analyze connections" — it executes.

### D. The Command Palette
*   `Ctrl + K` / `Cmd + K` — fuzzy-search all actions, notes, and commands instantly.

## 5. 𝗖𝗢𝗥𝗘 𝗪𝗢𝗥𝗞𝗙𝗟𝗢𝗪𝗦

### ⚛ Neural Fusion
Combine two ideas to create a third, evolved concept.
1.  **Drag & Drop**: Open Sidebar. Drag Note A onto Note B. Release.
2.  **Manual Mode**: Click the Atom icon. Select "Source". Select "Target".
3.  **Result**: A new note is spawned with a synthesized title, merged content, and a generated visualization.

### 👻 The Haunt
Discover hidden connections.
1.  While writing, click the **Ghost** icon in the toolbar.
2.  A panel reveals "Haunted By" notes — entries the AI deems semantically relevant.
3.  Click a ghost to jump to that note.

### ⚡ Live Session
Talk to your notes.
1.  Click the **Lightning** icon.
2.  Accept microphone permissions.
3.  Speak. The AI (Zephyr) responds instantly. Context-aware of your current note.
