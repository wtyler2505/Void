### Prerequisites
*   Node.js & npm/yarn
*   Google Cloud Project with **Generative Language API** and **Google Drive API** enabled.
*   An API Key with access to the Gemini 3.0 / 2.5 models.

### Boot Sequence

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/your-username/void.git
    cd void
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Environment Configuration**
    Set your `API_KEY` in the environment variables (e.g., `.env` or build configuration).
    ```bash
    export API_KEY="your_gemini_api_key"
    ```

4.  **Engage Systems**
    ```bash
    npm start
    ```
