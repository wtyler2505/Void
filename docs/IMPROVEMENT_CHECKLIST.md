# VOID — Improvement & Enhancement Checklist

A comprehensive checklist of every possible improvement, enhancement, and integration for VOID.

---

## AI / Intelligence
- [ ] AI-powered auto-tagging of notes based on content
- [ ] AI note summarization (condense long notes into key points)
- [ ] AI-powered writing suggestions / autocomplete as you type
- [ ] Smart search — semantic search across all notes using AI
- [ ] AI tone/style rewriting (formal, casual, technical, etc.)
- [ ] AI translation of notes to other languages
- [ ] AI-generated flashcards from note content
- [ ] AI-powered grammar and spell check
- [ ] Chat context awareness — let the AI reference all your notes, not just the current one
- [ ] AI-generated table of contents for long notes

## Editor Enhancements
- [ ] Full rich text / WYSIWYG editing (bold, italic, headings via toolbar)
- [ ] Code syntax highlighting in code blocks
- [ ] Drag-and-drop image embedding
- [ ] Drawing / sketching canvas within notes
- [ ] Tables support (insert and edit tables)
- [ ] Checklists / to-do lists with progress tracking
- [ ] Embeddable links with preview cards
- [ ] Split-pane editing (two notes side by side)
- [x] Focus / zen mode (distraction-free writing)
- [x] Word count goals and writing streaks
- [ ] Version history / undo timeline per note
- [x] Templates (meeting notes, journal, project plan, etc.)
- [ ] Slash commands (type `/` to insert blocks)
- [ ] Collapsible sections / folding
- [ ] Footnotes and annotations

## Organization & Navigation
- [ ] Folders / nested folder structure
- [ ] Note linking (wiki-style `[[note]]` links between notes)
- [ ] Knowledge graph visualization of linked notes
- [x] Pinned / favorited notes *(pre-existing)*
- [x] Archive functionality (hide without deleting) *(pre-existing)*
- [ ] Bulk actions (multi-select, delete, tag, move)
- [x] Custom sort options (alphabetical, size, last edited)
- [x] Color-coded tags or labels
- [ ] Note categories beyond tags
- [ ] Recent notes / quick access panel

## Collaboration
- [ ] Real-time collaborative editing (multiple users in one note)
- [ ] Shareable public links to individual notes
- [ ] Comments and annotations on shared notes
- [ ] User accounts with authentication
- [ ] Team workspaces
- [ ] Permission levels (view, edit, admin)
- [ ] Activity feed showing recent changes across shared notes

## Data & Storage
- [ ] PostgreSQL backend for persistent, server-side storage
- [ ] Full-text search with database indexing
- [ ] Automatic cloud backup on a schedule
- [ ] Import from other note apps (Notion, Evernote, Obsidian, Apple Notes)
- [ ] Trash / recycle bin with restore
- [ ] Note encryption (end-to-end)
- [ ] Storage usage indicator
- [ ] Offline-first with background sync

## Export & Sharing
- [ ] Export to PDF with styled formatting
- [ ] Export to DOCX (Word)
- [x] Export to HTML
- [ ] Print-friendly view
- [ ] Email a note directly
- [ ] Publish notes as a blog / public page
- [ ] RSS feed of published notes

## Multimedia
- [ ] Voice-to-text transcription improvements
- [ ] Audio note playback with speed controls
- [ ] Video note embedding from YouTube/Vimeo
- [ ] Image gallery view for notes with attachments
- [ ] OCR — extract text from images
- [ ] Screen recording integration
- [ ] File attachments (PDFs, spreadsheets, etc.)

## UI / UX
- [ ] Light theme / theme switcher
- [ ] Custom theme editor (pick your own neon colors)
- [ ] Responsive mobile layout improvements
- [ ] PWA support (installable on phone/desktop)
- [ ] Customizable sidebar width
- [ ] Compact vs. comfortable view density
- [ ] Animated transitions and micro-interactions
- [ ] Breadcrumb navigation
- [x] Global command palette (Cmd+K)
- [ ] Onboarding walkthrough for new users
- [ ] Notification system for reminders and events

## Integrations
- [ ] Stripe — premium tier with payment processing
- [ ] GitHub — save/sync notes to a repository
- [ ] Slack — share notes to channels
- [ ] Calendar integration — link notes to calendar events
- [ ] Notion import/export
- [ ] Zapier/webhook triggers on note changes
- [ ] Email-to-note (send an email, it becomes a note)
- [ ] Browser extension for clipping web content into notes
- [ ] OpenAI as an alternative AI provider
- [ ] Dropbox / OneDrive sync (beyond Google Drive)

## Productivity
- [ ] Reminders and due dates on notes
- [ ] Pomodoro timer built into the editor
- [ ] Daily journal prompt
- [ ] Habit tracker widget
