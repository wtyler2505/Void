# 🎮 𝗨𝗦𝗘𝗥 𝗠𝗔𝗡𝗨𝗔𝗟

> *Operator's Handbook for the VOID Interface.*

## 1. 𝗧𝗛𝗘 𝗜𝗡𝗧𝗘𝗥𝗙𝗔𝗖𝗘

### A. The Sidebar (Navigation)
The command center for your knowledge base.
*   **Search**: Real-time filtering by title, content, or tags.
*   **Tag Lattice**: Horizontal scroll of all tags in your vault. Click to filter.
*   **Fusion Mode (Atom Icon)**: Toggles the Neural Fusion selection interface.
*   **Live Mode (Flash Icon)**: Switches to the voice-only interface.
*   **Sync (Cloud Icon)**: Opens Google Drive backup controls.

### B. The Editor (Workspace)
Where the magic happens.
*   **Title**: Auto-generated by AI if left blank (based on content).
*   **Toolbar**: Access to AI tools (Summarize, Enhance, Visualize, Video, TTS, Haunt).
*   **Markdown Preview**: Toggle split view to see rendered text.
*   **Haunt Panel**: A slide-out panel showing semantically related notes.

### C. The Chat Overlay (Assistant)
A floating window activated by the "Chat" button.
*   **Context Aware**: The AI knows which note you are currently editing.
*   **Omnipotent**: You can tell it to "Delete this," "Make a new note," or "Add a tag" and it will execute the code.

## 2. 𝗖𝗢𝗥𝗘 𝗪𝗢𝗥𝗞𝗙𝗟𝗢𝗪𝗦

### ⚛ Neural Fusion
Combine two ideas to create a third, evolved concept.
1.  **Drag & Drop**: Open Sidebar. Drag Note A onto Note B. Release.
2.  **Manual Mode**: Click the Atom icon. Select "Source". Select "Target".
3.  **Result**: A new note is spawned with a synthesized title, content merging the ideas, and a generated visualization.

### 👻 The Haunt
Discover hidden connections.
1.  While writing, click the **Ghost** icon in the toolbar.
2.  The sidebar reveals "Haunted By" notes—entries the AI deems relevant.
3.  Click a ghost to jump to that note.

### ⚡ Live Session
Talk to your notes.
1.  Click the **Lightning** icon.
2.  Accept microphone permissions.
3.  Speak. The AI (Zephyr) responds instantly. It is aware of the note you were just viewing.

## 3. 𝗞𝗘𝗬𝗕𝗢𝗔𝗥𝗗 𝗦𝗛𝗢𝗥𝗧𝗖𝗨𝗧𝗦

| Action | Shortcut | Description |
|--------|----------|-------------|
| **New Note** | `Ctrl + N` | Instantly create a blank entry. |
| **Search** | `Ctrl + F` | Focus the sidebar search bar. |
| **Save** | `Ctrl + S` | Force write to IndexedDB immediately. |
| **Export** | `Ctrl + Shift + E` | Open export menu (MD, JSON, TXT). |
| **Archive** | `Ctrl + Del` | Move note to archive (Soft Delete). |
| **Delete** | `Ctrl + Shift + Del` | Permanently destroy note (Active or Archived). |
| **Switch** | `Ctrl + 1-9` | Jump to the Nth note in the list. |
| **Help** | `Ctrl + /` | Show shortcut cheat sheet. |
